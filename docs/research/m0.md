# M0 — Buffer (`@rawmark/buffer`)

Related Issue: https://github.com/matthewbub/rawmark/issues/1

- **Core**
  - Line-array buffer behind an interface: `getLine`, `lineCount`, `getValueInRange`, `applyEdit(range, text)`
  - Offset ↔ position conversion
  - Full Vitest coverage
- **AI**
  - Nothing. The buffer stays dumb — offsets, positions, edits with inverses.
  - Only verification: the `{range, text}` edit representation works identically for programmatic batch edits (AI) and keystrokes (user). It already does; just keep it true.
- **Done when**
  - Edits at every boundary pass: line start/end, multi-line delete, empty doc
